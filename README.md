# YouTube DisVanced - A YouTube Vanced revival!
## What's this?

YouTube DisVanced is a project made by me to recreate the original YouTube/YouTube Music Vanced experience, including the old YouTube layout. It's based on YouTube 19.29.40/YouTube Music 6.50.51 and uses inotia00's YouTube ReVanced Extended patches. It'll be constantly updated when something breaks server-side, specially the day when versions 19.51.01 - 20.53.00 die.

## Recreation list

With this I:
- Changed dependency of MicroG to original Vanced MicroG (com.mgoogle.android.gms)
- Changed YouTube and YouTube Music Vanced package name to the original one (com.vanced.android.youtube and com.vanced.android.apps.youtube.music)
- Added YouTube and YouTube Music Vanced's launcher icons and old YouTube app icons (Outline)
- Recreated the old YouTube design (By changing patching options and default enabled settings)
- Enabled YouTube Vanced's default settings (By changing default enabled settings)

## Dependencies

YouTube DisVanced needs these apps to work properly:
- Vanced MicroG
