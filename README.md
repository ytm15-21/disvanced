# YouTube DisVanced - A YouTube Vanced revival!

## What's this?

YouTube DisVanced is a project made by me to recreate the original YouTube/YouTube Music Vanced experience, including the old YouTube layout. It's based on YouTube 19.30.34/YouTube Music 6.50.51 and uses inotia00's YouTube ReVanced Extended patches. It'll be constantly updated when something breaks server-side, specially the day when versions 19.51.01 - 20.53.00 die.

## Recreation list

Doing this I:
- Changed dependency of MicroG to original Vanced MicroG (com.mgoogle)
- Changed YouTube and YouTube Music Vanced package name to the original one (com.vanced.android.google and com.vanced.android.apps.youtube.music)
- Added YouTube Vanced's launcher icon and old YouTube app icons (Outline)
- Recreated the old YouTube design (By changing patching options and default enabled settings)
- Enabled YouTube Vanced's default settings (By changing default enabled settings)
